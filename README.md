# Instituto Prause — Landing Page MELA

Landing page moderna de alta conversão para o procedimento **MELA (Mini Extração Lipídica Ambulatorial)** realizada pelo **Dr. Tiago Prause** (CRM SC 17341 | RQE 17614).

## 🚀 Tecnologias

- **HTML5 & Tailwind CSS**: Layout moderno e responsivo com alternância harmônica entre seções em Azul Escuro e Branco Gelo.
- **JavaScript Moderno**:
  - Modal inteligente de pré-avaliação e direcionamento direto para WhatsApp.
  - Abas interativas de casos clínicos reais autorizados (Antes e Depois).
  - Accordion interativo de Perguntas Frequentes (FAQ).
  - Barra fixa de ação móvel (Sticky CTA) e botão flutuante com indicador de status online.
- **Bun**: Servidor HTTP nativo e ultrarrápido para desenvolvimento local e produção.

## 🛠️ Como Executar Localmente

### Pré-requisitos
- [Bun](https://bun.sh/) instalado.

### Passos
```bash
# Iniciar o servidor
bun run server.ts

# Ou usando o script configurado
bun run start
```

Acesse no navegador:
👉 [http://localhost:3000](http://localhost:3000) (ou `http://localhost:3001` caso a porta 3000 esteja em uso).
